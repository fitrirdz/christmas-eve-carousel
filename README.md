# Christmas Eve Carousel

A festive web-based carousel celebrating Christmas Eve themes.

## Description

This project features an interactive horizontal carousel that showcases various Christmas Eve moments, from winter frost to the Christmas spirit. Users can scroll through the themes using buttons, markers, or keyboard arrows, while enjoying falling snowflake animations.

## Features

- Horizontal scrolling carousel with 7 festive themes
- Interactive scroll buttons and markers
- Keyboard navigation (arrow keys)
- Animated snowflakes for ambiance
- Responsive design

## How to Use

Open [index.html](index.html) in a web browser to view the carousel.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
